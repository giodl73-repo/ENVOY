# ENVOY context

ENVOY is the International Affairs 2.0 domain owner for Taxlane's INT track.
It distinguishes budget, obligation, disbursement, delivered output, partner
capacity, and durable outcome while preserving local incidence, diversion,
humanitarian, legal, security, and source-protection constraints.

Current flagship: an aggregate assistance-realization screen. It is not an
operational plan, country ranking, award decision, diplomatic instruction, or
official fiscal score.
